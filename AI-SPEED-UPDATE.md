# Ускорение ИИ — 5 ноября 2026

Обновление предназначено для той же ветки postgresql-password и запроса на объединение №2.

## Что изменено

- Общая конфигурация Ollama для всех помощников. По умолчанию используется установленная qwen3:4b-instruct, поэтому не требуется загружать вторую модель. OLLAMA_ORIGIN и ASSISTANT_MODEL задаются в .env; SUPPORT_MODEL допускает отдельную настройку справочного сервиса.
- Добавлено think:false: скрытое рассуждение отключено для более быстрого получения прямых ответов. Критерии оценивания, требования к цитатам, проверки JSON и контроль доступа сохранены.
- Модель предварительно загружается при запуске backend и по умолчанию остаётся в памяти 30 минут. Это занимает RAM, но уменьшает задержки повторной загрузки. Ошибка прогрева не останавливает обычные функции сайта.
- Изменяемая метка времени перенесена в конец справочного системного контекста, чтобы не разрушать стабильный префикс запроса.
- Контекст справочных запросов и проверки отчётов сохранён не меньше 8192 токенов. Структурированные ответы получили отдельный предел 1200 токенов для завершённого JSON; обычные ответы — 600. Эти значения настраиваются.
- В дополнительном помощнике предел обычного ответа снижен с 4096 до 600 токенов. Фоновый дополнительный вызов модели для автоматического запоминания диалога теперь включается явно через ASSISTANT_AUTO_MEMORY=1; по умолчанию выключен.
- Добавлена команда npm run ai:check: проверка наличия моделей, прогрев и тестовый ответ. DEPLOY.md содержит команды установки модели, создания alias и проверки перед запуском.

## Локальные измерения

Одна и та же Qwen3 4B Q4_K_M, два одинаковых вопроса, без личных данных:

| Проба | До | После |
| --- | ---: | ---: |
| Короткий отчёт, три пункта | 12,704 с | 5,874 с |
| Название файла, одно предложение | 2,722 с | 2,388 с |

Первый замер включает влияние состояния загрузки модели и кеша. После изменения модель была предварительно прогрета. Это небольшая диагностическая выборка, а не доказательство одинакового ускорения на всех серверах. Ответы различались по длине. Скорость зависит от CPU/GPU, RAM, модели, контекста и одновременной нагрузки.

Готовность npm run ai:check подтверждена реальным ответом за 0,709 с на уже загруженной модели. Реальная оценка тестовой идеи прошла за 11,365 с, вернула валидные критерии, приоритет и вывод. Это не замер производительности удалённого сервера.

Семь целевых серверных тестов прошли: настройки Ollama, сохранение JSON-схемы/контекста, изоляция файлов и задач, локальные знания и проверки оценивания отчётов. Модели Ollama, секреты и пользовательские документы в обновление не включаются.

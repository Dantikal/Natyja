# Натыйжа

Система задач, отчётов, рейтинга и предложений. React + Express + MySQL; ИИ работает через локальный Ollama.

Инструкция для администратора сервера: [DEPLOY.md](DEPLOY.md).

В репозиторий передаются исходники и структура БД. Пароли, действующая база, пользовательские фотографии, документы, история ИИ и локальные программы не включены. Старые аккаунты на новом сервере автоматически не появятся.

Проверки и известные ограничения: [SECURITY-REVIEW.md](SECURITY-REVIEW.md), [PERFORMANCE-REVIEW.md](PERFORMANCE-REVIEW.md).

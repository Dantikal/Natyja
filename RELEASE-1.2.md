# Версия 1.2

Снимок исходного кода от 12 ноября 2026.

База пользователей, загруженные документы, секретные настройки, сертификаты, виртуальное окружение и node_modules не включены.

Frontend: cd frontend1; npm install; npm run dev
Backend: установите зависимости из backend/requirements.txt, настройте окружение по backend/.env.example, затем выполните миграции и запустите manage.py runserver.

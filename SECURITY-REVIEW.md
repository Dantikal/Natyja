# Проверка безопасности — 4 ноября 2026

Проверен локальный проект. Это проверка кода и зависимостей, а не полный аудит работающего публичного сервера. Абсолютная безопасность не гарантируется.

## Исправлено

- Фото больше не сохраняются с расширением пользователя: sharp проверяет формат JPEG/PNG/WEBP, ограничивает число пикселей, повторно кодирует в JPEG и удаляет метаданные. Имя генерируется криптографически. Ограничены multipart-поля.
- Закрыта выдача внутренних сообщений SQL/БД из обработчиков с HTTP 500.
- Добавлены nosniff, запрет framing и object embeds, ограничения базового URL и политика referrer.
- Убрана отдельная обработка assistant-support в шлюзе: запросы проходят через общую серверную защиту и лимиты.
- Шлюз удаляет недоверенные forwarded host/proto; доступ к локальной папке знаний запрещён для всех запросов через публичный шлюз, включая соединения туннеля с localhost.
- CF-Connecting-IP доверяется только при явной настройке TRUST_CLOUDFLARE_HEADERS=true. Включать исключительно за настроенным доверенным туннелем/прокси, исключающим прямой доступ к шлюзу. Иначе лимиты за туннелем могут применяться совместно ко всем посетителям.
- Backend по умолчанию слушает 127.0.0.1. BIND_HOST позволяет явно выбрать другой адрес.
- CORS ограничен локальными адресами разработки; дополнительные доверенные origins задаются через CORS_ORIGINS (через запятую). Публичный интерфейс с API на том же origin продолжает работать без CORS.
- JWT принимает только Bearer и алгоритм HS256. Минимум пароля при регистрации увеличен до 8 символов; bcrypt cost — 12; смена пароля ограничена по частоте.
- Загрузка отчётов ограничивает расширения и количество полей. Source maps закрыты публичным шлюзом.
- Удалены неиспользуемые серверные UI-зависимости, обновлены bcrypt, multer и доступные исправления npm. Удалён неиспользуемый react-quill-new из frontend.
- Добавлен .gitignore для секретов, загрузок, логов и локальных резервных копий.

## Проверки

- Backend npm audit: 0 известных уязвимостей (до обновлений: 11, включая 1 critical).
- Frontend npm audit: 78 предупреждений (11 low, 54 moderate, 13 high; до обновлений: 87). Это число записей npm, а не доказанных способов атаковать опубликованный сайт. Большая часть связана с react-scripts и его сборкой/тестами, но анализ всех путей эксплуатации не выполнен.
- 13 серверных тестов прошли: CAPTCHA, throttling, изоляция документов/задач, запрет удалённого доступа к локальным знаниям, проверка изображений, заголовки, оценки отчётов.
- 24 клиентских набора / 40 тестов прошли.
- Production build успешно собран.
- assistant.test.cjs падает на проверке попадания собственного исправления пользователя в контекст модели. Проверка отсутствия чужого исправления перед этим проходит. Причина не устранена; этот набор нельзя считать успешным.

## Остающиеся работы и ограничения

- Требуется обновление/замена старой цепочки react-scripts и устранение оставшихся предупреждений с повторной проверкой сборки. npm audit fix --force не применялся: он предлагает в том числе react-scripts@0.0.0 и ломает инструменты проекта.
- Фото пока доступны по публичным URL. Для персональных военных данных следует отдельно реализовать защищённую выдачу фото и адаптировать компоненты интерфейса, которые используют прямые img URL. Старые загрузки не перекодировались и не сканировались.
- Документы проверяются по ограничениям загрузки и расширению, но антивирусная проверка и изоляция всех парсеров не реализованы.
- Требуется аудит опубликованного домена, HTTPS, туннеля/прокси, ОС, MySQL, секретов, резервных копий и матрицы доступа с настоящими тестовыми аккаунтами. Публичный адрес в задаче не указан; сетевой пентест не выполнялся.
- Существующие процессы не перезапускались. Серверные исправления требуют перезапуска backend и public-site.cjs. Собран frontend/build; шлюз может сразу начать отдавать эту сборку.
- Копии изменяемых исходников сохранены в .codex-backup/security-20261104. Резервные копии исходных package-lock до обновления не создавались: первая попытка скрипта резервирования через Python завершилась до выполнения.

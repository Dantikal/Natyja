Local OCR language data for Russian and English. Keep this directory when copying the application to another computer.

Files rus.traineddata and eng.traineddata were downloaded from https://github.com/tesseract-ocr/tessdata_fast on 2026-11-02, under the Apache License 2.0 (see LICENSE). OCR uses local Tesseract.js; user images are not sent to an OCR service. Kyrgyz OCR and general image understanding are not provided.
